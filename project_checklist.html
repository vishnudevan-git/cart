7 — Order Lifecycle

0 / 0 ▾
▸ Normal Flow (Supplier-fulfilled)
Customer places order → status: Pending
Shop confirms → status: Confirmed
Stockist picks from supplier → status: Picked from Supplier
Stockist delivers to shop → status: At Local Store
Shop marks out-for-delivery → status: Out for Delivery
Shop marks delivered → status: Delivered, COD payment auto-closed to Paid
▸ Express Flow (Shop has stock)
If shop has all items in stock, order starts at At Local Store (skips supplier/stockist)
Customer sees 4-step Express timeline (not 6-step)
▸ Partial Delivery
Shop can deliver some items, collect partial COD → status: Partially Delivered
Customer sees per-item status (Delivered / On the way / Coming soon)
COD collection history shows each instalment (batch 1: ₹X, batch 2: ₹Y)
▸ Cancellation
Order can be cancelled from Pending / Confirmed / any non-final stage
